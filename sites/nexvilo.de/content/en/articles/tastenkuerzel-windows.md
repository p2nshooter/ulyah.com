Anyone who works on a computer uses the mouse thousands of times a day: open the menu, search for a command, click, go back to the keyboard. With a few keyboard shortcuts, many things are quicker, more convenient and protect your wrist and nerves. You don't have to memorize them all. Even ten well-chosen combinations will noticeably change your everyday working life. This overview presents the most useful keyboard shortcuts for Windows 11, sorted by situation and gives you a plan on how to actually remember them.

## The most important buttons are briefly explained

Before we get started, a look at the keys that appear in almost all combinations:

- **Ctrl** (control, on English keyboards “Ctrl”) at the bottom left.
- **Alt** next to the space bar.
- **Shift** (the key with the up arrow, also “Shift”) for capital letters.
- **Windows key** with the Windows logo, usually between Ctrl and Alt.
- **Tab** with the two arrows above the Caps Lock key.
- **Delete** (remove) and **Backspace** (the left arrow above the Enter key).

A key combination like **Ctrl + C** means: Hold down Ctrl and then briefly press C. Then release both keys.

## The ten abbreviations that everyone should know

| Keyboard shortcuts | What happens |
|---|---|
| **Ctrl + C** | Copy selected |
| **Ctrl + X** | Cut out what is marked |
| **Ctrl + V** | Insert |
| **Ctrl + Z** | Undo last step |
| **Ctrl + Y** | Redo what was undone |
| **Ctrl + A** | Mark everything |
| **Ctrl + S** | Save |
| **Ctrl + F** | Search in the document or on the web page |
| **Alt + Tab** | Switch between open windows |
| **Windows + L** | Lock computer |

Just **Ctrl + Z** is a lifesaver: If you accidentally deleted a paragraph, moved a file or overwritten something, this combination will take you back a step almost anywhere. And **Windows + L** is something you should get into the habit of using as soon as you get up from your desk, in the office or at home, when there are children or guests around.

## Windows and windows under control

### Arrange windows with Snap

Windows 11 can arrange windows neatly next to each other. This is particularly useful if, for example, you are writing a text and need a website or email next to it.

- **Windows + left/right arrow:** Pin windows to the left or right half of the screen.
- **Windows + up arrow:** Maximize window.
- **Windows + arrow down:** Shrink or minimize window.
- **Windows + Z:** Open Snap Layouts. You choose a grid, perhaps three columns or four quarters, and assign the windows using the arrow keys.

### Switch between windows and desktops

- **Alt + Tab:** Hold Alt and tap Tab several times to cycle through open windows.
- **Windows + Tab:** Shows all windows and virtual desktops in an overview.
- **Windows + D:** Minimize all windows and show the desktop. Pressing it again restores it.
- **Windows + Ctrl + D:** Create a new virtual desktop, for example one for work and one for private purposes.
- **Windows + Ctrl + Left/Right Arrow:** Switch between virtual desktops.
- **Alt + F4:** Close the active window. On the empty desktop, the combination opens the shutdown menu.

## Screenshots and screen recordings

- **Windows + Shift + S:** Opens the Snipping Tool. You use the mouse to select an area, a window or the entire screen. The image ends up on the clipboard and can be saved or edited.
- **Print key** (often “Print”, “PrtSc” or “PrtScn”): In Windows 11 it usually also opens the snipping tool. You can find the setting under *Settings > Accessibility > Keyboard*.
- **Windows + Print:** Instantly saves an image of the entire screen in the *Images > Screenshots* folder.
- **Windows + Shift + R:** Starts a screen recording as a video in the Snipping Tool, useful for showing someone a process.

Before sharing a screenshot, check whether it shows any private information such as email addresses, account numbers, or names and redact it with the pen in the Snipping Tool.

## The clipboard with memory

Normally the clipboard only remembers what was last copied. Use **Windows + V** to open the **Clipboard History**. There you will see the last 25 copied texts and images and can choose what you want to paste. The first time you open it you have to turn on the history.

You can **pin** frequently used entries there, such as your address or a standard answer, then they will be retained even after a restart. But don't copy passwords to history, and turn off syncing between devices when copying sensitive content.

## Edit text faster

These shortcuts work in Word, email programs, browsers and most other programs:

- **Ctrl + left/right arrow:** Make the cursor jump word by word.
- **Ctrl + Shift + Left/Right Arrow:** Select word by word.
- **Home / End:** Jump to the beginning or end of the line.
- **Ctrl + Home / Ctrl + End:** Jump to the beginning or end of the document.
- **Shift + Home/End:** Select to the beginning or end of the line.
- **Ctrl + Backspace:** Delete the entire word to the left of the cursor.
- **Ctrl + Shift + V:** Paste without formatting in many programs, useful when copied text from the Internet wants to keep its font.
- **Ctrl + B / I / U:** Bold, italic, underlined (in German Office versions partly **Ctrl + Shift + F**, **K** and **U**).

### Emojis and special characters

- **Windows + period (.)**: Opens the selector for emojis, symbols and special characters such as €, ©, → or ½. You can immediately type to search, like “Heart.”
- **Alt Gr + E:** The Euro symbol €.
- **Alt Gr + Q:** The @ sign.

## The Explorer: Manage files faster

- **Windows + E:** Open Explorer.
- **F2:** Rename the selected file.
- **Ctrl + Shift + N:** Create a new folder.
- **Del:** Move to trash. **Shift + Del** permanently deletes without trash, so be careful.
- **Alt + Enter:** Show properties of the file.
- **Ctrl + Mouse Wheel:** Enlarge or reduce symbols.
- **Alt + Up Arrow:** Go up one folder level.

## In the browser

Almost the same abbreviations apply in Edge, Chrome and Firefox:

- **Ctrl + T:** Open new tab.
- **Ctrl + W:** Close current tab.
- **Ctrl + Shift + T:** Restore an accidentally closed tab. Works multiple times in a row.
- **Ctrl + Tab:** Switch to the next tab.
- **Ctrl + L:** Jump to the address bar.
- **Ctrl + Plus / Minus / 0:** Zoom in, zoom out, reset page. Helpful with small font.
- **Ctrl + Shift + N** (Chrome, Edge) or **Ctrl + Shift + P** (Firefox): Open private window.
- **F5:** Reload page. **Ctrl + F5** reloads it without buffering.

## System and help

- **Windows key:** Open start menu. You can immediately tap to search for programs, settings, or files.
- **Windows + I:** Open Settings.
- **Windows + A:** Quick settings for Wi-Fi, Bluetooth, volume and brightness.
- **Windows + N:** Notifications and Calendar.
- **Windows + X:** A menu containing important system tools such as Device Manager and Disk Management.
- **Ctrl + Shift + Esc:** Open Task Manager directly when a program hangs.
- **Windows + Plus:** Turn on screen magnifier. **Windows + Esc** turns it off again.
- **Windows + H:** Voice input. You speak, Windows writes.

## Help for people with limited vision or movement

Windows offers keyboard shortcuts that make working easier:

- **Windows + Ctrl + Enter:** Narrator reads what is on the screen.
- **Left Alt + Left Shift + Print:** High contrast on and off.
- **Five times Shift:** Snap feature that lets you press key combinations one after the other instead of at the same time. Practical if it is difficult to press at the same time.

You can find further settings under *Settings > Accessibility*.

## Abbreviations in Word, Excel and Outlook

Anyone who works a lot with Office will benefit from a few additional combinations:

- **Ctrl + N:** New document, spreadsheet or email.
- **Ctrl + P:** Print.
- **F7:** Start spell checker in Word.
- **Ctrl + Enter:** Insert a page break in Word, send an email in Outlook. You should know the latter in particular so that you don't send a half-finished message.
- **F2** in Excel: Edit the selected cell.
- **Ctrl + arrow key** in Excel: Jump to the end of a data range.
- **Ctrl + Shift + L** in Excel: Turn filter on and off.
- **Alt + Enter** in Excel: Insert a line break within a cell.
- **Ctrl + R** in Outlook: Reply to one email, **Ctrl + Shift + R** reply to all, **Ctrl + F** forward. Attention: In Outlook, Ctrl + F does not open the search, but redirects.

On the **Mac** most of the shortcuts are similar, except that the command key ⌘ takes over the role of Ctrl. So instead of Ctrl + C it is ⌘ + C.

## This is how you remember the abbreviations

Nobody learns fifty keyboard shortcuts at once. A step-by-step approach has proven successful:

1. **Choose three shortcuts per week** that fit your everyday life, such as Windows + V, Windows + Shift + S and Ctrl + Shift + T.
2. **Write it on a piece of paper** and stick it to the edge of the screen.
3. **Force yourself to use the shortcut instead of the mouse for a week**.
4. **Add three new ones in the next week.**

After a month you will know twelve abbreviations without thinking about it. Many programs also display the appropriate keyboard shortcut next to the commands in their menus when you hover over them.

## Own abbreviations and help programs

If you want even more, you can use the free **Microsoft PowerToys** to set your own keyboard shortcuts, reassign keys or open a quick program launcher with **Alt + Spacebar**. For desktop shortcuts, you can enter your own shortcut in the properties of a shortcut under “Key combination”.

## Frequently asked questions

**Why isn't a keyboard shortcut working for me?**
Some laptops assign special functions such as volume or brightness to the top keys F1 to F12 by default. Then you also have to press the **Fn key**, such as Fn + F2 to rename. On many devices this can be switched with Fn + Esc. Programs can also set their own shortcuts that cover the Windows shortcuts.

**Can I accidentally break something?**
Most shortcuts are harmless and can be undone with Ctrl + Z. You only need to be careful with Shift + Del because the file won't end up in the trash, and with Alt + F4 if unsaved work is open. In this case, most programs ask whether you want to save.

**Is there an overview to print out?**
Microsoft provides a complete list of Windows keyboard shortcuts on its help pages. However, a self-written list with your ten most important abbreviations is more helpful in everyday life.



## Conclusion

A handful of keyboard shortcuts will make you noticeably faster on the computer: copy, paste and undo anyway, plus Alt + Tab for switching, Windows + arrow keys for arranging, Windows + Shift + S for screenshots and Windows + V for the clipboard history. Learn the shortcuts gradually, three per week, and use Windows + L every time you leave your seat. After a few weeks you won't want to go back.
